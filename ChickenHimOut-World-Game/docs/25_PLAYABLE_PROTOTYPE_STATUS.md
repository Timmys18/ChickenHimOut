# Статус первой запускаемой версии

## Что уже собрано
- Первая миссия создаётся автоматически.
- Игрок может цеплять и тянуть галстук касанием.
- Есть этапы миссии от первого действия до побега.
- Есть подсказки, которые появляются только после бездействия.
- Есть оценка результата по цели, хаосу, стилю и ущербу.
- Есть экран победы и поражения.
- Есть мгновенный повтор миссии.
- Есть сохранение результата и запись прохождения для анализа.
- Есть звук и вибрация на ключевых событиях.
- Есть автоматическая проверка структуры проекта и обязательных файлов.

## Что ещё требует реального запуска Unity
- Проверить отсутствие ошибок компиляции.
- Открыть автоматически созданную сцену и проверить связи между объектами.
- Проверить управление мышью и касанием.
- Собрать Android APK.
- Запустить APK на реальном телефоне.
- Проверить частоту кадров, нагрев и расход памяти.
- Получить видео первого полного прохождения.

## Условие перехода к следующему этапу
Следующий этап считается подтверждённым только после реального прохождения миссии на телефоне без ручного вмешательства в сцену.
