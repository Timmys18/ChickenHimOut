# Claude + Codex: работа одной AI-командой

## Что уже настроено

В проект добавлена связка, при которой:

- ты общаешься только с Claude;
- Claude руководит работой и вызывает Codex самостоятельно;
- Codex реализует задачи в той же папке проекта;
- Claude проверяет изменения и возвращает Codex замечания;
- тебе приходит один понятный итог без технической переписки между агентами.

Для этого в проекте уже лежат:

- `CLAUDE.md` — постоянные правила для Claude;
- `AGENTS.md` — постоянные правила для Codex;
- `.mcp.json` — соединение Claude с Codex;
- `START_AI_TEAM.cmd` — запуск двойным кликом;
- `scripts/setup-ai-team.ps1` — автоматическая установка и проверка нужных программ.

## Первый запуск

1. Обнови проект из GitHub, чтобы эти файлы появились на компьютере.
2. Открой папку проекта.
3. Дважды нажми `START_AI_TEAM.cmd`.
4. Скрипт сам проверит Git, Node.js, Claude Code и Codex и установит недостающее.
5. При необходимости откроется вход в Codex через аккаунт ChatGPT.
6. Затем запустится Claude. При первом запуске войди в аккаунт Claude.
7. Claude спросит, разрешить ли проектное подключение `codex`. Разреши его.

После этого повторная работа начинается тем же двойным кликом по `START_AI_TEAM.cmd`.

## Как ставить задачу

Пиши обычным языком. Например:

> Сделай магазин скинов. Сам изучи проект, обсуди решение с Codex, поручи ему реализацию, проверь результат и верни на исправление, если найдёшь проблемы.

Или короче:

> Исправьте вместе с Codex зависание после завершения миссии и полностью проверьте результат.

Дополнительно объяснять распределение ролей не нужно: оно уже записано в проекте.

## Что будет происходить без твоего участия

1. Claude изучит задачу и проект.
2. Claude передаст Codex точное техническое поручение.
3. Codex изменит файлы и запустит проверки.
4. Claude посмотрит фактические изменения и повторно проверит проект.
5. При необходимости Claude отправит Codex замечания.
6. После исправлений Claude даст тебе итог человеческим языком.

## Когда система всё-таки спросит тебя

Только когда требуется:

- выбрать продуктовый или визуальный вариант;
- предоставить недоступный аккаунт или пароль;
- оплатить внешний сервис;
- опубликовать сборку или изменить production;
- удалить данные или выполнить другое необратимое действие.

Технические решения внутри обычной разработки команда принимает сама.

## Если запуск остановился

Окно не нужно закрывать сразу: внизу будет написана конкретная причина. После её устранения снова нажми `START_AI_TEAM.cmd`.

Чаще всего первый запуск останавливается только ради входа в ChatGPT или Claude. Это единственная часть, которую нельзя безопасно выполнить вместо владельца аккаунтов.
